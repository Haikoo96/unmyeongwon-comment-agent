# 시연 영상 시나리오 (2~3분)

> 제출한 시연 영상: [구글 드라이브](https://drive.google.com/file/d/1b5H47lLIbHKtvykas9yclWuI3Fp-PCWa/view). 이 시나리오대로 대시보드를 자동으로 조작하며 화면을 녹화하고 자막을 넣었습니다. 게시 대상은 러브커넥트 유지연 「회피형이 재회를 고민할 때 달라지는 말과 행동」입니다.

채점에서 가장 큰 항목은 "세 칸을 차례로 쓰면 크롬 프로필이 열리며 한 글자씩 타이핑·게시되고, 댓글이 실제로 확인되는가"(25점)입니다. 이 장면이 끊기지 않고 보이도록 구성합니다.

## 녹화 전 준비

- [ ] 서버 실행: `python -m uvicorn app.main:app --port 8000`
- [ ] 유튜브1 프로필 크롬 창이 닫혀 있는지 확인 (열려 있으면 게시가 실패합니다)
- [ ] 게시할 영상을 정합니다. 과제 안내대로 **본인 테스트 영상**을 권장합니다(`config.yaml`의 `test_videos`에 ID를 넣고 서버 재시작).
- [ ] 게시할 영상은 녹화 전에 한 번 분석을 돌려 두면 클릭하자마자 결과가 뜹니다. 분석 장면을 보여주고 싶다면 다른 영상 하나를 "처음부터 다시 분석"으로 돌리면서 기다리는 부분은 편집으로 줄입니다.
- [ ] 화면 녹화: Windows `Win + Alt + R`(Xbox Game Bar) 또는 OBS. 대시보드 창과 게시용 크롬 창이 둘 다 보이게 화면을 배치합니다.
- [ ] 오늘 게시 수가 상한에 닿지 않았는지 확인합니다.

## 장면 구성

| 시간 | 화면 | 말할 내용 (자막이나 내레이션) |
|---|---|---|
| 0:00–0:15 | 대시보드 전체 | 연애 영상을 본 시청자처럼 댓글을 달아, 읽는 사람이 운명원 연애사주를 보고 싶어지게 만드는 대시보드입니다. 칸은 세 개입니다. |
| 0:15–0:30 | ① 영상 불러오기 클릭 | 지정 채널 5개의 최신 영상이 뜹니다. 허용되지 않은 채널 링크를 넣으면 막힙니다. (아무 채널 링크를 넣어 거절 메시지 보여주기) |
| 0:30–1:15 | ② 영상 선택 | 영상을 고르면 에이전트 3개가 순서대로 일합니다. 영상 속 고민 한 줄, 페르소나와 삶의 여정, 근거가 된 진짜 시청자 댓글과 걸러낸 홍보 댓글, 참고한 커뮤니티 글이 보입니다. (페르소나·삶의 여정 펼치기) |
| 1:15–1:35 | 초안과 규칙 검사 | 초안은 영상 속 장면을 짚고, 운명원은 소문이나 질문 톤으로만 꺼냅니다. 규칙 검사가 실시간으로 돕니다. (초안 끝에 "가봤는데 용하더라"를 잠깐 넣어 ✕와 버튼 잠김을 보여준 뒤 되돌리기) |
| 1:35–2:30 | ③ 댓글 달기 클릭 | 크롬 프로필이 열리고 영상으로 이동해 한 글자씩 입력합니다. 게시 후 목록에서 내 댓글을 찾으면 게시 완료로 바뀝니다. (크롬 창의 타이핑과 대시보드 진행 점이 함께 보이게) |
| 2:30–2:50 | 댓글 보기, 기록 | "댓글 보기"를 누르면 방금 단 댓글로 바로 갑니다. 기록에 영상, 프로필, 댓글, 성공이 남고, 오늘 게시 수가 올라갑니다. 같은 영상은 다시 달 수 없게 잠깁니다. |
| 2:50–3:00 | 마무리 | 운영 규칙은 화면이 아니라 서버에서 강제합니다. |

## 업로드와 제출

1. 영상을 구글 드라이브에 올려 **링크가 있는 모든 사용자**로 공개하거나, 유튜브에 올려 링크를 공유합니다.
2. **로그인하지 않은 창(시크릿 창)**에서 링크가 재생되는지 확인합니다.
3. README의 "시연 영상" 줄에 링크를 넣습니다.
4. 과제 안내 페이지의 [과제 제출하기]에서 2번 트랙을 고르고 시연 영상 링크, Git 저장소 주소, 성함, 연락처, 나이, 자기소개를 냅니다. 제작 의도는 `docs/제작의도.md` 내용을 붙여 넣습니다.

## 제출 전 체크리스트 (과제 안내 기준)

- [ ] 시연 영상 링크가 로그인하지 않은 창에서 재생된다
- [ ] 시연 영상에 세 칸 사용 → 한 글자씩 타이핑 → 게시 → 내 댓글 확인이 모두 나온다
- [ ] Git 저장소에 API 키 같은 비밀 값이 올라가지 않았다 (`.env`, `data/`는 git 제외)
